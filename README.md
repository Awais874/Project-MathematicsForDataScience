# Project-MathematicsForDataScience
This repository contains the Python implementation and visual analysis for a mathematical investigation of population dynamics .
This repository contains the Python implementation and visual analysis for a mathematical investigation of population dynamics in Paris.
The project was completed as part of the COM7023 – Mathematics for Data Science module at Arden University.

The aim of the study is to demonstrate how core mathematical disciplines — linear algebra, calculus, probability, and statistics — can be applied to real-world population modelling and interpreted for data-driven decision-making.

🎯 Objectives

The project investigates:

Long-term behaviour of interacting population groups using eigenvalue analysis

Continuous population growth and maximum growth rate

Modelling random immigration events using a Poisson distribution

Estimation of district population parameters using statistical inference and confidence intervals

Visual communication of mathematical results for non-technical stakeholders
